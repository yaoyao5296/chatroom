Privacy Policy

Last updated: 2026-08-19

Data Collection

ChatRoom does not collect, store, or transmit any personal data to the developer or to any third-party service.

Where Data Lives

All user data (messages, accounts, files) is stored locally on the user's own self-hosted ChatRoom server instance. The developer has no access to user data.

No Tracking

The application does not include any analytics, advertising, crash reporting, or tracking SDKs.

Network Access

Network connections are made only to the server URL that the user explicitly configures. No background data collection or telemetry occurs.

Permissions

The app may request: Internet access (to connect to the user's chat server), Storage access (for file/image uploads configured by the user). No other permissions are required.

Open Source

ChatRoom is open source under the MIT License. The full source code is available at github.com/yaoyao5296/chatroom for anyone to audit.
